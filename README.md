# 🌐 Nishant Borah — Personal Portfolio Website

A modern and dynamic **personal portfolio website** built using **pure HTML and CSS**, designed to showcase my profile, interests, and creative journey as a web enthusiast and technology learner.  
The site features a **Black & Gold Aurora theme**, symbolizing elegance, ambition, and leadership — inspired by my Leo personality and passion for innovation.

---

## ✨ Overview

This portfolio serves as a digital introduction to who I am —  
a student, creator, and aspiring technologist studying at **Scaler School of Technology** in collaboration with **BITS Pilani**.  

It includes multiple responsive sections such as:
- **Home** — A minimal introduction with my name, title, and quick links.  
- **About** — A short personal story highlighting my interests in **Web Development, Robotics, and AI**.  
- **Skills** — A showcase of the core technologies I’m currently learning.  
- **Projects** — Placeholder section with “Launching Soon” and “Blueprint Under Construction” animations.  
- **Contact** — Quick access to my **GitHub**, **LinkedIn**, and **Gmail**.

---

## 🧠 Tech Stack

- **HTML5** for structure  
- **CSS3** (Flexbox + Grid) for layout and responsiveness  
- **CSS-only animations** for the glowing **Aurora background** and interactive elements  
 

---

## 🖤 Theme: Black & Gold Aurora

The entire site uses a **black base** with animated **gold gradients**, creating a premium, elegant feel while keeping the design minimal.  
All motion is powered by **pure CSS keyframes**, ensuring high performance even without JS.

```css
--aur1:#facc15;
--aur2:#fbbf24;
--aur3:#eab308;
--aur4:#d97706;
```

## 🚀 How to Run

1. Open the folder in **VS Code**.  
2. Right-click on `index.html` → **Open with Live Server**.  
3. Navigate using the dropdown **Menu** button.  
4. Works smoothly on both **desktop and mobile**.
